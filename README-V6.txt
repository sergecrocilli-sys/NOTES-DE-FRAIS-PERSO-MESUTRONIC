MESUTRONIC — NOTES DE FRAIS V6

Évolution V6 : moteur de lecture OCR renforcé, sans clé API et sans stockage des photos.

Chaîne de lecture :
1. photo temporaire ;
2. recadrage automatique du ticket lorsque possible ;
3. agrandissement jusqu'à 2400 px ;
4. variante gris contrasté + netteté ;
5. variante noir/blanc adaptatif pour papier thermique ;
6. variante noir/blanc fort ;
7. trois lectures OCR Tesseract ;
8. comparaison et vote des résultats ;
9. date priorisée si cohérente avec le mois/année sélectionnés ;
10. montant priorisé près de TOTAL, TTC, À PAYER, CB, CARTE, etc. ;
11. classification métier puis proposition modifiable ;
12. export Excel identique à la V5.

Aucune photo n'est conservée après une lecture réussie. Les lignes utiles du mois restent stockées localement sur l'appareil.
